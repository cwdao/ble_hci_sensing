# 针对性的部分建议

可以，而且我认为这比强行把 Phase 包装成“互补增益来源”更可信、更有研究价值。但贡献的准确表述不应是：

> “BLE CS 的相位很差，所以不应该使用。”

而应当是：

> **BLE CS 的双向组合相位不是一个稳定、普适的第三观测模态；它在受控周期运动中可能有效，但在自然人体呼吸和复杂多径环境中可靠性明显下降。无条件融合全部可用变量反而可能损害性能，因此 BLE CS 需要 measurement-aware modal selection，而不是 more-is-better fusion。**

这可以成为论文中的一个重要实验发现和设计原则。

------

## 1. 为什么这个结论可以构成贡献

负面结果只有在回答了一个合理、重要且尚不明确的问题时，才是贡献。你这里恰好满足：

### 原本合理的假设

从复信道的一阶扰动模型看：

- Remote/Local amplitude 是径向投影；
- composite phase 是切向投影；
- 径向与切向在数学上互补；
- 因此，一个很自然的设计是融合三种模态。

这不是随意尝试，而是一个有物理依据的假设。

### 实验却给出了系统性反例

你目前的证据链已经比较完整：

| 证据                    | 结果                | 支持的结论                              |
| ----------------------- | ------------------- | --------------------------------------- |
| HKH Remote-only         | 0.376 BPM           | 幅值单模态稳定                          |
| HKH Local-only          | 0.378 BPM           | 两端幅值近似对等                        |
| HKH Phase-only          | 2.191 BPM           | Phase 在真人域明显不稳定                |
| HKH R+L                 | **0.372 BPM**       | 不需要 Phase 就能达到当前最优           |
| HKH 三模态等权          | 0.405 BPM           | 无条件加入 Phase 造成退化               |
| Phase rescue rate       | 18%                 | Phase 偶尔有帮助                        |
| Phase destruction rate  | **49%**             | 破坏频率显著高于救援频率                |
| Phase oracle 增益上限   | 0.028 BPM           | 即使有 GT 帮助选择，潜在收益仍很小      |
| Phase waveform fidelity | Δr = −0.081         | Phase 也没有提供更好的波形保真度        |
| Phase gate              | 相对 R+L 无显著增益 | 可观测指标暂时不能稳定释放 Phase 的潜力 |
| CS 金属板 Phase         | 与幅值接近          | Phase 不是始终不可用，而是场景依赖      |

因此，你得到的不是一次“算法没调好”，而是一个层次清楚的发现：

1. Phase 在理想机械周期运动中可以工作；
2. 但这种能力没有稳定迁移到真人自然呼吸；
3. Phase 偶尔救援，但总体破坏多于救援；
4. 即使 oracle 选择，增益上限也很小；
5. 简单质量门控暂时无法改变这一结论。

这足以支撑一条有意义的 BLE CS 设计结论。

------

## 2. 最合适的论文定位

我建议把 Phase 结论定位为：

### **“组合相位的条件性可靠性”**

而不是：

- “Phase 完全无用”；
- “BLE CS Phase 天生不可用于感知”；
- “低成本设备的 Phase 一定比 amplitude 差”。

更稳妥的英文表述可以是：

> **Composite phase is a conditionally useful but statistically unreliable modality for natural respiration sensing under the evaluated commodity BLE CS implementation.**

或者：

> **The mathematical complementarity between radial amplitude and tangential phase projections does not automatically translate into practical fusion gain.**

再进一步形成设计原则：

> **Availability is not reliability: exposing an additional physical observable does not imply that it should always participate in sensing fusion.**

这句话其实很适合作为论文 Discussion 的核心观点之一。

------

## 3. 不建议直接声称“低成本设备导致相位不行”

你的推断有合理性，但目前证据还不足以把因果完全归结到“低成本嵌入式设备”。

你现在直接测量到的是：

> 在当前 Nordic BLE CS 平台、当前 CS 配置、当前事件率、当前人体数据和处理链下，组合 Phase 的实际可靠性明显低于两端 amplitude。

但你还没有完全分离以下因素：

1. 双端相位误差叠加；
2. 两端 LO/校准残差；
3. 低 SNR 下的 PCT 相位估计误差；
4. phase unwrap 错误；
5. 2–4 Hz 稀疏采样；
6. 人体非正弦呼吸和身体微动；
7. 复杂多径导致切向投影不稳定；
8. 组合 Phase 是两个端侧切向分量的和，可能发生抵消；
9. 不同芯片或天线配置是否会得到同样结论。

因此，论文中最好写：

> The observed degradation likely results from the composite nature of phase, accumulated endpoint measurement noise, and reduced cross-tone coherence under natural respiration and multipath.

不要写成：

> Low-cost BLE hardware makes phase unusable.

同样，“两端噪声相加使方差等于单端两倍”需要独立同分布、互不相关等假设。若没有直接噪声实验，建议写成：

> The composite phase potentially accumulates errors from both endpoint measurements.

而不是把“2 倍方差”写成已经实验证明的事实。

------

## 4. Phase 最有价值的结论不是“差”，而是“域依赖”

你最有意思的结果其实是 HKH 和 CS 金属板的反差：

| 场景      | Phase-only             | 最优策略   |
| --------- | ---------------------- | ---------- |
| HKH 真人  | 2.191 BPM，明显较差    | R+L        |
| CS 机械板 | 10.92%，与 Remote 接近 | 三模态融合 |

这说明 Phase 不是简单的“坏信号”，而是：

> **对运动规律性、跨 tone 相干性和场景多径结构更加敏感。**

可以形成一个更强的机制解释：

- 机械板运动频率稳定、位移规律、近似单一周期成分；
- 真人呼吸存在非正弦形态、频率漂移、身体微动和更复杂的动态散射；
- amplitude 即使波形形态受影响，通常仍保持较稳定的呼吸频率峰；
- Phase 对这些扰动可能更加敏感，导致跨 tone 峰频共识下降；
- 这与 HKH Phase confidence 0.324、CS Phase confidence 0.402 的差异一致。

因此，“Phase 在真人域崩坏而在机械域正常”本身就是 BLE CS 生理感知与机械感知之间的重要区别。

------

## 5. 对最终论文主线的建议

我建议将论文中心故事调整为以下四层。

### 第一层：BLE CS 不是低采样率 WiFi CSI

其双向 PCT 产生：

- 两个端侧 amplitude；
- 一个双端 composite phase；
- 三者的噪声来源和稳定性并不对称。

### 第二层：Tone diversity 是主要增益来源

这是你最强、最稳定的定量结果：

> 1.640 → 0.381 BPM。

72 个 tone 提供的频率分集是系统性能的主要来源。

### 第三层：Modal diversity 不是越多越好

最关键的反直觉发现：

> R+L = 0.372，而 R+L+P 等权 = 0.405。

也就是说：

> **多一个具有不同物理意义的观测量，并不必然产生 diversity gain。**

只有当新增模态具备足够可靠性，而且其互补信息超过噪声注入时，模态融合才有价值。

### 第四层：BPM 与波形需要不同融合域

- BPM：质量加权谱融合；
- 波形：相干对齐；
- Phase：条件性辅助观测，而非默认参与者。

这样论文会比“我们设计了三模态融合，结果三模态最好”更真实，也更有洞察力。

## 6. Phase 应不应该继续放进最终主算法？

根据现有结果，我倾向于：

### 主方法默认采用 R+L

特别是目标应用是人体呼吸时：

- R+L 已经达到 0.372；
- Phase oracle 上限只有 0.028；
- Phase gate 相对 R+L 没有显著增益；
- 增加 gate 会引入阈值、LOSO 和实现复杂度；
- 但实际性能收益尚未得到证实。

因此最干净的最终方法可能是：

> **BreatheCS 主管线：tone-level η·ρ Voting + R/L amplitude modal fusion。**

### Phase gate 作为扩展或分析方法

可以在论文中保留：

- `Amplitude-only BreatheCS`：最终推荐方法；
- `Phase-gated BreatheCS`：跨域自适应扩展；
- `Three-modal equal fusion`：直观但不可靠的 baseline；
- `Phase oracle`：潜在收益上限。

如果 unified pipeline 最终实验发现 gate：

- HKH 不劣于 R+L；
- CS 接近三模态最优；
- 阈值 LOSO 稳定；
- 在不使用场景标签的情况下完成选择；

那么它可以作为“跨域稳健版本”。

但如果结果仍然只是“平均接近 R+L、统计不显著”，就不建议把 gate 写成论文的核心算法贡献。否则审稿人很可能问：

> 既然 R+L 更简单、性能相同，为什么还需要 Phase gate？

这时最好的回答不是继续增加算法复杂度，而是将 gate 定位为：

> 用于验证 Phase 条件性角色的诊断实验，而非最终必要模块。

## 7. 你当前 plan 中有几处需要先统一

### 7.1 CS 没有波形 GT，却安排了 CS waveform RMSE

plan 中已经多次说明：

> CS 金属板无呼吸带 GT 波形，不能计算 waveform RMSE。

但执行指令又要求：

> CS 波形单模态基线 Remote/Local/Phase RMSE 首次测量。

这两者矛盾。除非机械装置能提供同步位移轨迹，否则 CS 只能评估：

- 波形分支输出的 BPM error；
- 谱峰质量；
- 周期一致性；
- 跨 tone/modal coherence；
- 或相对于已知理想正弦的相关性，但这不能等同于真实 waveform RMSE。

因此应删除所有“CS waveform RMSE”要求，或者明确改成：

> CS waveform-branch BPM relative error，非 waveform RMSE。

### 7.2 Gate 的论文地位与现有统计结论不一致

advisor briefing 已经写明：

> Phase 门控相对 R+L 无统计显著增益。

但 unified plan 又把 gate 当作最终统一管线的核心 Stage 2。建议在实验完成前把它定义成：

> **candidate adaptive extension**

而不是已经确定的最终方法组件。

### 7.3 MS-QWDC 的理论解释不要写得过满

“误选污染期望为 $p/N$”目前更像启发式解释，未必是严格成立的统计结论。因为融合污染通常还取决于：

- 错误候选的权重；
- 错峰距离；
- 候选之间的相关性；
- 投票归一化方式；
- 假阳性是否集中在同一个频点。

因此建议将其表述为：

> With 72 tone candidates, isolated prominence false positives are diluted by consensus aggregation; with only three modalities, one erroneous high-prominence modality can directly dominate the fusion.

这已经足够合理，不必过早上升到 James–Stein 或经验贝叶斯理论。除非后面建立正式概率模型，否则把它写成“empirically supported sample-size-dependent regularization principle”更安全。

> 从复信道微扰模型看，幅值与相位分别对应径向和切向投影，二者在数学上具有互补性。然而，物理投影的互补性并不等同于实际测量可靠性的互补性。在受控机械周期运动中，组合相位能够形成与幅值相近的稳定呼吸峰；但在真人自然呼吸中，其跨 tone 一致性和波形保真度均明显下降。进一步的 oracle 分析表明，即使利用 ground truth 选择最有利于 Phase 的窗口，其 BPM 改善上限仍然有限；同时，Phase 对已有正确结果的破坏频率显著高于其救援频率。因此，在当前 BLE CS 平台和实验条件下，组合相位更适合作为条件性辅助观测，而非默认参与融合的第三模态。该结果说明，无线感知系统不应仅根据物理变量的可获得性决定融合结构，还必须考虑不同观测量在目标场景中的统计可靠性。

## 10. 最终判断

**是的，这完全可以成为贡献。** 但最有价值的贡献不是简单证明“Phase 不好”，而是证明：

1. **理论互补性不保证实际融合增益；**
2. **BLE CS composite phase 的可靠性具有明显的场景依赖性；**
3. **无条件全变量融合会损害真人呼吸感知；**
4. **tone diversity 的价值远高于 modal diversity；**
5. **对于当前人体数据，R+L amplitude 是更可靠、更简单的默认方案；**
6. **Phase 应被视为条件性辅助观测，其真正盲区填补能力仍需工作点扫描实验验证。**

这比勉强宣称 Phase 提升了零点零几 BPM 更有说服力。诚实、系统地证明“为什么一个看似合理的变量不应被默认融合”，本身就是 measurement-aware sensing 的重要设计发现。

# 一、先给出总体建议

## 1. 论文主方法和 Phase 分析应当分开

建议把最终论文区分为两部分：

### 主方法：稳定、简单、由真人数据支持

- tone-level：$\eta\cdot\rho$ 质量加权的多 tone 谱融合；
- BPM branch：优先使用 Remote + Local amplitude；
- waveform branch：根据最终实验，在 Remote-only 和 R+L coherent MRC 中选择；
- BPM 与 waveform 使用不同融合域。

### Phase：作为一个系统性的测量可靠性研究

Phase 不必从论文中删除。相反，可以保留为一个重要发现：

- 物理上对应切向投影；
- 受控机械运动中可以工作；
- 真人呼吸中跨 tone 一致性下降；
- rescue 少于 destruction；
- oracle 上限很小；
- 无条件三模态融合会退化；
- 当前质量指标不能稳定判断何时应该启用 Phase。

也就是说，Phase 从“必须进入主算法的第三模态”改为：

> **一个有理论互补性、但实际可靠性受场景限制的条件性观测量。**

------

## 2. 下一步实验不应再默认 gate 是最终核心模块

目前证据已经表明：

- HKH 上 R+L = 0.372；
- gated Phase 相对 R+L 没有显著增益；
- Phase oracle 上限仅 0.028 BPM；
- gate 的主要价值可能不是提高单域性能，而是避免在 HKH 和 CS 之间手工选择不同策略。

所以建议把 unified plan 中的 Phase gate 从：

> 最终管线必需的 Stage 2

调整为：

> **待验证的跨域自适应扩展。**

最终结果可能有两种：

### 情况 A：gate 稳定且确实实现跨域自适应

如果：

- HKH 上交叉验证结果不劣于 R+L；
- CS 上接近三模态最优；
- 阈值在各 LOSO fold 中稳定；
- 无明显 recording-level 灾难性退化；

- 没有实质改善；
- 阈值随 fold 波动；
- 部分 recording 明显受损；
- Phase 启用行为与预期不稳定；

那么论文主方法应直接使用 R+L，gate 只作为 Phase 分析实验。

根据现有结果，我认为**情况 B 的概率更高**，但统一实验仍值得完成，因为它能给出最终决策依据。

# 三、理论和建模章节需要修正的问题

## 1. 修正幅值一阶展开公式

当前 Equation (4) 存在变量混用。建议使用标准的一阶近似：

$Z_d(t)=\bar Z_d+\delta Z_d(t)$

当 $|\delta Z_d|\ll|\bar Z_d|$ 时：

$\frac{\delta A_d(t)}{\bar A_d} \approx \operatorname{Re} \left\{ \frac{\delta Z_d(t)}{\bar Z_d} \right\}$

$\delta \phi_d(t) \approx \operatorname{Im} \left\{ \frac{\delta Z_d(t)}{\bar Z_d} \right\}.$

如果进一步令：

$\delta Z_d(t)=V_d\xi(t),$

则：

$\frac{\delta A_d(t)}{\bar A_d} \approx \operatorname{Re} \left\{ \frac{V_d}{\bar Z_d} \right\}\xi(t),$

而不是当前文档中的：

$\operatorname{Re}\{V_d/\bar Z_d\}\delta Z_d(t).$

当前公式在量纲和变量含义上都不一致。

## 7.3 Why Physical Complementarity Does Not Guarantee Fusion Gain

这是论文最重要的新增 Discussion。

可直接表达为：

> 幅值与相位对应不同复平面投影，证明了二者“可能包含不同信息”；但这并不证明两者具有相同噪声水平、相同跨 tone 一致性或相同的呼吸波形保真度。因此，projection complementarity 是潜在信息层面的结论，而 diversity gain 是有效信息超过噪声代价后的统计结论。前者成立并不保证后者成立。

- 身体微动；
- 复杂动态散射；
- phase unwrap；
- 低事件率下的相位估计敏感性；
- 跨 tone peak coherence 下降。

不要把原因单独归结为“低成本设备相位质量差”，除非以后有硬件噪声对比实验。

- waveform-branch BPM relative error；
- peak concentration；
- coherence；
- periodicity；
- 与理想正弦的相关性——但必须明确这不是对真实位移波形的 RMSE。

因此输出应调整为：

### HKH

- BPM absolute error；
- waveform RMSE；
- waveform correlation，可选。

### CS

- BPM relative error；
- confidence/coherence；
- Phase activation rate；
- 不报告 waveform RMSE。

CS 图也不应再做“谱域 + 波形 RMSE 分面”。

------

## 5. LOSO 设计需要更严谨

HKH 实际是：

- 4 subjects；
- 每 subject 3 recordings；
- 共 12 recordings。

所以应写：

> 4-fold leave-one-subject-out，每 fold 留出一个 subject 的 3 条 recording，使用其余 3 位 subject 的 9 条 recording 选择阈值。

不是“其余 9 个 recording”之外再暗示有 10 个 subject。

### 阈值选择建议

候选：

$\theta\in\{0.30,0.35,0.38,0.40,+\infty\}.$

其中：

- $+\infty$：始终关闭 Phase，即 R+L；
- 也可以把 always-on 三模态单独作为 baseline。

加入“Phase 永不启用”非常重要。否则优化器被迫选择某个 gate，即使实际最优就是不用 Phase。

### 报告方式

- HKH gate 性能必须使用 held-out fold 的 out-of-sample predictions；
- 不能在全 HKH 上选阈值后再报告同一批数据；
- CS 使用 4 个 LOSO training folds 所选阈值的中位数；
- CS 上不再重新调阈值。

### Tie-breaking

如果多个阈值训练误差接近，建议预先规定：

> 选择更保守、Phase 激活率更低的阈值。

因为已有证据显示 Phase destruction risk 较高。

------

## 6. Gate 的定义必须完全固定

不能继续保留：

> “最高 bin 票数 / 总票数，或使用原 Voting confidence”。

必须定义唯一实现：

$\mathrm{conf}_m = \frac{\max_b \sum_{i:f_i\in b}w_i} {\sum_i w_i+\epsilon}.$

同时固定：

- histogram bin width；
- frequency range；
- peak interpolation 是否在投票前使用；
- invalid tone 的定义；
- 最低 $\eta$ 阈值；
- 没有 valid tone 时的 fallback。

否则 $\theta=0.35$ 没有可复现意义。

------

## 7. Stage 1 的“Voting”和“加权谱”要分清楚

当前文档同时描述：

- histogram Voting；
- weighted spectrum；
- 最终 BPM 从 fused spectrum 得到。

建议统一术语：

### Tone consensus

使用 peak histogram 得到：

- consensus peak；
- confidence。

### Tone spectral aggregation

使用 $\eta\rho$ 加权归一化谱得到：

- $\bar S_m(f)$。

最终 BPM 从 $\bar S_m(f)$ 或 modal fused spectrum 寻峰。

这样不要再笼统地把整个过程都叫 Voting。论文可以称为：

> quality-weighted tone consensus and spectral aggregation。

------

## 8. Waveform RMSE 协议必须冻结

需要在 plan 中明确以下内容：

1. 输出与 GT 是否重采样到同一时间轴；
2. z-score 是 per-window 还是 per-recording；
3. 是否允许极性翻转；
4. 是否允许时间延迟校正；
5. 延迟是 per-window、per-recording 还是全局；
6. overlapping window 如何拼接；
7. recording-level RMSE 如何计算。

尤其要防止：

> 每个窗口都用 GT 寻找最佳 lag 或最佳 sign。

这会引入 oracle 信息，使 RMSE 偏乐观。

推荐做法是：

- 只允许 recording-level 固定时间偏移；
- 所有方法使用同一个对齐协议；
- 如果允许极性不确定，则只允许每条 recording 一个全局 polarity；
- 不允许逐窗利用 GT 调整融合相位。

如果现有 baseline 已使用另一套协议，就应保持兼容，但必须完整披露。

------

## 9. 统计单位需要重新考虑

当前 plan 写：

> main statistical unit = recording，12 HKH。

但 12 条记录来自 4 位重复受试者，每人 3 个场景，不是完全独立。

建议：

### 性能汇总

仍可报告 12-recording mean ± std。

### 置信区间

使用 subject-cluster bootstrap：

- 以 subject 为 cluster；
- 每次抽样 subject；
- 抽中 subject 后保留其全部 3 条 recordings；
- 计算 paired difference。

这比把 12 条 recording 当成独立样本更严谨。

不过只有 4 位 subject，因此统计功效很有限。不要让论文结论过度依赖“显著/不显著”，应同时报告：

- mean difference；
- cluster bootstrap CI；
- 逐 recording 差值；
- 最坏退化；
- Phase activation rate。

CS 只有 3 条，不建议重点强调置信区间。CS 更适合描述性跨域验证。

# 九、修订后的成功标准

不要只写“是否达到预期数值”，建议改成决策标准。

## 1. Spectral branch

### 选择 R+L 为主方法，如果：

- R+L 在 HKH 上优于或不劣于 Remote；
- 明显优于 all-modal equal；
- gate 没有产生稳定的额外收益；
- gate 阈值不稳定或引入 recording-level 退化。

### 选择 gated pipeline 为主方法，如果：

- HKH out-of-sample 结果相对 R+L 实际不劣；
- CS 明显优于 R+L，并接近三模态最优；
- 各 LOSO fold 阈值相对稳定；
- gate 行为与 confidence 分布一致；
- 没有明显灾难性退化。

这里“不劣”可以预先给一个实际容忍范围，例如 0.02–0.03 BPM，而不是仅依赖 $p$-value。

------

## 2. Waveform branch

### 选择 R+L coherent MRC，如果：

- RMSE 低于 Remote-only；
- 多数 subject/recording 都有改善；
- 改善不是由单条 recording 驱动；
- 没有明显 morphology 退化。

### 选择 Remote-only，如果：

- R+L 平均改善极小；
- 部分 recording 明显变差；
- Local 融合没有稳定 diversity gain。

### 只有在 gated Phase 确实改善 RMSE 时才保留 Phase

否则 Phase 不进入主 waveform branch。

# 十四、最终推荐的论文故事

> BreatheCS 研究了如何利用 BLE Channel Sounding 的双向、多频观测进行非接触呼吸感知。研究发现，BLE CS 的主要性能增益来自跨 72 tone 的频率分集，而不是简单增加观测模态。基于这一发现，BreatheCS 使用质量驱动的 tone aggregation，并针对呼吸率和波形恢复分别采用谱域融合和复平面相干重建。进一步实验表明，尽管 composite phase 在数学上与 amplitude 形成径向/切向互补投影，它在自然人体呼吸中的统计可靠性显著低于端侧幅值；无条件融合 Phase 对正确结果的破坏多于救援。该结果说明，BLE CS 感知应区分物理可观测性与实际测量可靠性，并采用选择性而非全变量融合。

这个故事有三个清晰贡献：

1. **测量模型**：BLE CS 双向 PCT 观测不能按 WiFi CSI 直接处理；
2. **方法设计**：tone-quality aggregation + task-specific dual branches；

## 一、先给结论：贡献是成立的，但目前属于“故事已经足够，证据规模仍偏弱”

就你现在的材料看，这篇文章**已经具备一篇完整研究论文所需的贡献闭环**：

1. 提出了 BLE CS 双向 PCT 的呼吸观测模型；
2. 识别出 BLE CS 与 WiFi CSI 不同的测量结构和融合问题；

4. 用消融证明 tone diversity 是主要增益来源；
5. 系统证明 composite phase 的物理互补性没有稳定转化为真人呼吸中的实际融合增益；
6. 给出了“只融合可靠观测，而不是融合全部可用变量”的设计原则。

所以，问题已经不是“有没有贡献”，而是：

> **如何避免把贡献写成几个普通信号处理模块的组合，同时避免对 Phase、理论性和性能优势作过度宣称。**

如果叙事处理得好，这是一篇有明确研究发现的 BLE CS sensing 论文；如果处理不好，审稿人可能会把它理解为：

> “把加权谱、Hilbert 和 MRC 拼在一起，在 4 个受试者上做了一个呼吸实验，而且最后发现 Phase 不好用。”

两种评价之间的差别，主要来自论文如何组织“研究问题—证据—设计结论”，而不只是最终 0.372 或 0.951 这些数字。

# 二、贡献充分，但要分清“方法贡献”和“研究发现贡献”

这篇论文最忌讳把所有贡献都压在算法新颖性上。因为从单个模块看：

- Welch/FFT 频谱融合不是全新的；
- $\eta$ 和峰值突出度加权不是全新的统计思想；
- Hilbert 解析信号对齐不是全新的；
- MRC 不是全新的；
- threshold gate 也不是全新的。

如果论文声称核心贡献是“提出一种全新的融合算法”，容易被质疑算法新颖性不足。

你真正强的地方是：

> **第一次围绕 BLE CS 特有的双向 PCT 观测结构，系统研究 tone、endpoint amplitude 和 composite phase 应当如何参与呼吸感知，并从实验中建立一组不同于 WiFi CSI 的融合原则。**

因此，贡献应由三个层次组成。

------

## 贡献一：BLE CS 呼吸观测模型与测量特性

核心不是简单介绍 BLE CS，而是回答：

- 双向 PCT 最终产生哪些适合感知的观测量？
- Remote/Local amplitude 和 composite phase 分别响应复信道微扰的什么分量？
- 为什么 total amplitude 没有带来独立观测信息？
- 为什么 BLE CS 不能简单视为低速 WiFi CSI？
- 为什么 tone 之间和模态之间需要不同的融合原则？

建议表述为：

> We formulate a respiration-oriented observation model for reciprocal BLE Channel Sounding measurements, distinguishing two endpoint amplitude observables from a composite-phase observable and characterizing their different sensitivities, noise pathways, and reliability under controlled and natural respiration.

这里不要声称 Remote、Local、Phase 是“三个独立观测量”。更安全的是：

> 三种具有不同物理敏感方向和误差来源的观测模态。

------

## 贡献二：测量感知、任务分离的双分支处理框架

这一条才是方法贡献：

- 共享质量驱动的 tone aggregation；
- BPM 使用谱域融合；
- waveform 使用相干复平面对齐；
- modal inclusion 根据可靠性，而不是根据“物理上可获得”来决定。

最重要的不是某个权重公式，而是：

> **同一组 BLE CS 测量，不应该强迫 BPM 和 waveform 使用同一种融合表示。**

建议表述为：

> We develop a task-oriented framework that shares a quality-aware tone aggregation front-end but separates timing-robust spectral rate estimation from coherent waveform reconstruction.

如果最终实验表明 waveform 使用 Remote-only 更稳，而不是 R+L，也不影响这一贡献。双分支的统一性来自共同的测量模型和质量前端，不来自所有分支使用完全相同的模态。

------

## 贡献三：BLE CS 分集增益层级与 Phase 可靠性发现

这是目前最有特点的实验贡献：

- tone diversity：稳定、主要、可重复；
- modal diversity：边际、条件性；
- composite phase：机械周期运动可用，但真人呼吸中明显不稳定；
- 物理互补性不等于统计融合收益；
- 无条件融合全部变量可能退化。

建议写成：

> Through fusion-level ablation, single-modal evaluation, oracle analysis, rescue–destruction analysis, waveform-fidelity comparison, and confidence gating, we reveal a hierarchy of diversity gains: tone diversity provides the dominant and consistent benefit, whereas modal diversity—particularly composite phase—is reliability-limited and scene-dependent.

这一条不是普通的“Phase 负面结果”，而是：

> **对 BLE CS 观测可靠性边界的系统刻画。**

------

# 三、这篇论文真正应该讲什么故事

我建议把全文收敛成一句中心论点：

> **BLE CS 呼吸感知的关键不是融合所有可用观测，而是识别不同尺度和不同任务下哪些观测足够可靠：频率维度的 tone diversity 提供主要增益，而 composite phase 的物理互补性只在部分场景中转化为实际价值。**

英文可以写成：

> **Effective respiration sensing with BLE Channel Sounding requires reliability-aware, task-specific fusion: tone diversity provides the dominant gain, while physical complementarity across endpoint amplitudes and composite phase does not guarantee practical modal diversity.**

这条主线比“我们提出一种三模态融合方法”更强，也更难被实验反驳。

------

# 四、推荐采用“问题驱动”而不是“算法模块驱动”的叙事

不要按下面这种普通方式叙述：

```text
我们有三种变量
→ 计算质量指标
→ 做频谱融合
→ 做 Hilbert MRC
→ 得到结果
```

这种写法很容易被评价为工程组合。

建议围绕四个研究问题展开。

------

## RQ1：BLE CS 为呼吸感知提供了什么不同的测量原语？

回答：

- 不是单端复 CSI；
- 是双向 PCT；
- 提供两个 endpoint amplitudes 和一个 composite phase；
- 实际事件率较低；
- tone 和 modal 的可靠性结构不同。

对应证据：

- 观测模型；
- PCT 组合；
- inter-tone/inter-modal 相位关系；
- 事件率和窗口长度分析。

------

## RQ2：BLE CS 的主要分集增益来自哪里？

回答：

> 主要来自 72-tone frequency diversity，而不是简单增加模态。

最强证据：

$1.640 \rightarrow 0.381\ \text{BPM}.$

而三模态等权反而：

$0.381 \rightarrow 0.405.$

这一节应该是论文实验的中心。审稿人即使不同意你对 Phase 机制的解释，也很难否认完整消融得到的增益层级。

------

## RQ3：为什么 BPM 与 waveform 要使用不同处理域？

回答：

- BPM 只要求频率稳定；
- 频谱幅值不受剩余时间相位影响；
- waveform 需要保持时序形态；
- 因此需要相干对齐。

对应证据：

- spectral branch BPM 优于 waveform branch BPM；
- waveform branch 在 RMSE 上优于迁移 baseline；
- sign correction 与 continuous Hilbert alignment 对比；
- level-1 与 level-2 alignment 的消融。

注意不要说“低采样率下时域方法无法工作”，而应说：

> 时域对齐在当前事件率、窗口长度和 SNR 下更敏感，因此不适合作为主 BPM 输出，但仍然是恢复波形结构所必需的。

------

## RQ4：Composite phase 是否提供了稳定的互补信息？

回答不能简单是“否”，而应分层：

1. 数学上，它对应不同的投影；
2. 受控机械运动中，它能够形成正确、稳定的周期峰；
3. 真人呼吸中，它的跨 tone 一致性和波形保真度下降；
4. rescue 少于 destruction；
5. oracle 上限很小；
6. gate 没有证明其在 HKH 上带来稳定增益；
7. 所以它是条件性观测，不是默认第三模态。

这个论证非常重要，因为它表明你没有因为一个实验结果不好就直接删除 Phase，而是完整检验了：

- 它理论上是否可能有用；
- 何时有用；
- 有多大上限；
- 能否用无 GT 指标识别；
- 加入后是否净收益为正。

这正是严谨研究，而不是失败调参。

------

# 五、叙事上最重要的转变：不要把 0.372 当成论文的核心胜利

R+L 的 0.372 相比 Remote 的 0.376，只改善了 0.004 BPM。这个差距很小，不适合作为主性能贡献。

如果论文写成：

> 我们提出最终 R+L 管线，把性能从 0.376 提升到 0.372。

审稿人很容易认为方法收益没有意义。

真正应强调的性能链是：

$\text{Uniform/no reliable tone aggregation: }1.640$

$\downarrow$

$\text{Quality-aware tone aggregation: }0.381$

然后说明：

> modal-level strategy 决定系统能否保留该收益，而不是继续获得同量级提升。

也就是说：

- tone aggregation 负责“获得主要收益”；
- modal policy 负责“不把收益破坏掉”。

因此，R+L 的价值不是将 0.376 大幅降到 0.372，而是：

> 用一个简单、稳定的 modal policy 保持 tone-level fusion 已经获得的性能，避免 composite phase 将误差重新推高到 0.405 甚至更差。

这是完全不同的叙事。

------

# 六、Phase 结论怎样写才不容易被攻击

## 不要写成

> BLE CS Phase 很差。

这会立即引出：

- 是不是你的算法不好？
- 是不是 unwrap 出错？
- 是不是这款芯片的问题？
- 是不是受试者位置问题？
- 是不是 Phase 本来就不适合与呼吸带比较？
- 换一个硬件平台是否仍成立？

------

## 应该写成

> Under the evaluated BLE CS implementation and natural-respiration settings, composite phase was less statistically reliable than endpoint amplitude and did not provide a positive net contribution to unconditional modal fusion.

中文：

> 在所评估的 BLE CS 平台和真人自然呼吸场景中，组合相位的统计可靠性低于端侧幅值，且无条件加入组合相位没有产生正向净融合收益。

这个表述同时限定了：

- 平台；
- 数据；
- 场景；
- 任务；
- 结论范围。

------

## 更进一步的机制表述

建议把下面这组区分明确写进论文：

### 物理互补性

表示两个变量对复信道扰动的不同方向敏感，因而**可能含有不同信息**。

### 统计可靠性

表示该变量是否具有：

- 稳定的呼吸频率峰；
- 足够的跨 tone 一致性；
- 较高波形保真度；
- 低假峰率；
- 在融合后提供正向净收益。

因此：

> **Physical complementarity is a statement about potential information; diversity gain is a statement about usable information after measurement noise and estimation error.**

中文：

> **物理互补性描述潜在信息方向，而分集增益取决于测量噪声和估计误差之后仍可利用的信息。前者成立并不保证后者成立。**

这是整个 Phase 章节最重要的理论句子。

------

# 七、最容易被审稿人质疑的地方

目前最大的风险不是 Phase 结果，而是以下几个问题。

------

## 1. 受试者规模偏小

当前只有：

- 4 位受试者；
- 每位 3 个场景；
- 共 12 条真人记录。

12 条 recording 不能完全视为 12 个独立样本，因为它们只有 4 个独立 subject。

这可能是全文最大的实验弱点。

### 处理方法

如果条件允许，最有价值的新增实验不是继续尝试算法变体，而是增加：

- 受试者数量；
- 不同体型、性别和呼吸模式；
- 重复日期；
- 不同设备摆位；
- 至少一个新的测试环境。

如果暂时无法扩充数据，应：

- 明确说是 4 subjects，而不是只强调 12 scenarios；
- 报告 subject-level 结果；
- 使用 subject-cluster bootstrap；
- 不过度强调统计显著性；
- 将结论限定为当前 cohort；
- 在 limitations 中主动说明。

对于一般应用型论文，这个规模可能可以接受；对于要求较高的系统或普适生理感知论文，这个规模会偏弱。

------

## 2. 单个算法模块的新颖性有限

审稿人可能说：

> 加权谱、Hilbert alignment 和 MRC 都是已有工具。

你的回应不能是“我们的公式稍有不同”，而应是：

> 本文创新不在于重新发明这些基本算子，而在于从 BLE CS 特有的双向测量结构出发，确定不同尺度、不同模态和不同任务应该使用什么融合域，并通过完整消融证明这些选择。

因此，论文题目、摘要和贡献中应使用：

- measurement-aware；
- observation-driven；
- task-specific；
- systematic characterization；
- diversity hierarchy。

少使用：

- novel weighting formula；
- novel MRC；
- theoretically optimal；
- first-ever algorithm。

------

## 3. Phase 的因果解释仍不充分

你已经证明 Phase 在 HKH 中表现差，但尚未完全证明为什么差。

当前可以支持的是相关性结论：

- Phase confidence 更低；
- Phase waveform fidelity 更差；
- Phase destruction 更高；
- 机械运动中 Phase 正常；
- 真人呼吸中 Phase 不稳定。

还不能确定是：

- 芯片相位噪声；
- 双端误差累积；
- 切向成分抵消；
- unwrap；
- 多径；
- 非正弦呼吸；
- 身体微动；
- 稀疏采样；

中的哪一个主导。

所以 Discussion 应写成“可能机制”，而不是明确因果判定。

工作点扫描实验如果完成，可以验证投影互补性；但它仍未必能完全解释真人域 Phase 退化。论文中要把：

- 已实验证明的；
- 由模型推导的；
- 基于结果推测的；

三者明确区分。

------

## 4. Gate 可能被认为是不必要复杂化

如果 gate 没有明显优于 R+L，审稿人会问：

> 为什么不直接不用 Phase？

因此最终论文有一个非常重要的原则：

> **只有当 gate 在 out-of-sample HKH 上不劣，并且在 CS 上自动恢复三模态优势时，才把它写进主方法。**

否则：

- R+L 是主方法；
- gate 是 Phase reliability study；
- 不要为了让方法看起来复杂而强行保留。

简单但得到充分支持的方法，比复杂但没有净收益的方法更容易说服审稿人。

------

## 5. “MS-QWDC 理论”可能被认为包装过度

目前 MS-QWDC 是一个不错的概括框架，但还不是严格理论。

特别是：

> $N=72$ 所以可以用 $\eta\rho$，$N=3$ 所以必须用 $\eta$-only。

这目前是经验支持的设计原则，不是一般性定理。

建议写成：

> empirically supported scale-dependent quality weighting

不要直接上升为：

- 新的统计学习理论；
- 严格的 bias–variance 定理；
- $p/N$ 的普适污染定律；
- James–Stein 类理论结果。

如果写得太满，审稿人只需要要求证明，就会暴露不足。

------

## 6. Waveform RMSE 的协议容易被质疑

审稿人会关注：

- 是否逐窗用 GT 找最佳 lag？
- 是否允许逐窗翻转符号？
- 是否用 GT 帮助选择参考模态？
- overlapping window 如何重建？
- z-score 是逐窗还是逐 recording？
- 呼吸带与无线信号存在的生理延迟如何处理？

必须保证：

> GT 只用于最终评估，而不参与每窗融合或对齐决策。

如果允许对齐，最好是：

- 每 recording 一个固定 lag；
- 每 recording 一个固定 polarity；
- 所有方法使用同一协议；
- 不允许逐窗 oracle alignment。

------

# 九、建议建立“主张—证据”对应表

在修改论文前，可以先内部建立如下表格，确保每个主张都有直接证据。

| 论文主张                       | 直接证据                       | 不能扩大到的结论                  |
| ------------------------------ | ------------------------------ | --------------------------------- |
| tone diversity 是主要增益      | 1.640 → 0.381                  | 不能说所有场景中 72 tone 一定最优 |
| spectral branch 更适合 BPM     | spectral BPM 优于 waveform BPM | 不能说时域 BPM 理论上不可行       |
| Hilbert alignment 改善波形融合 | sign/Hilbert 消融、RMSE        | 不能说 Hilbert 是唯一可行方法     |
| Phase 在 HKH 不可靠            | 2.191、低 conf、低 fidelity    | 不能说所有 BLE CS Phase 都不可用  |
| Phase 作用域依赖               | HKH 与 CS 对比                 | 不能直接确定域差异的唯一物理原因  |
| all-modal fusion 可能退化      | R+L 0.372 vs 3-modal 0.405     | 不能说 modal fusion 永远无用      |
| gate 可跨域自适应              | 需最终 out-of-sample 实验      | 未完成前不能作为既定结论          |
| R+L waveform 优于 Remote       | 需最终 RMSE 实验               | 未测前不能写进摘要                |

这张表能有效避免全文出现“证据只支持 A，文字却写成 A+B+C”的问题。

# 十、什么结果能让文章明显更强

按价值排序，我建议是：

## 第一优先级：增加真人数据

这是最直接补强外部有效性的方式。

------

## 第二优先级：完成统一但克制的收敛实验

明确最终：

- spectral 使用 R+L 还是 gate；
- waveform 使用 Remote 还是 R+L；
- gate 是否只是分析工具。

------

## 第三优先级：完成工作点扫描

如果成功，可形成非常漂亮的结论：

> 幅值与相位在受控工作点上确实具有物理互补性，但这种潜在互补性在真人自然呼吸中没有稳定转化为统计增益。

这会把 Phase 的负面结果从“Phase 不好”提升为：

> **从理想物理互补到实际测量可靠性之间存在 gap。**

------

## 第四优先级：跨硬件或跨配置验证

哪怕只增加一种：

- 不同设备对；
- 不同天线；
- 不同 event interval；
- 不同 Tx power；

也能帮助判断 Phase 问题是否高度依赖当前实现。

------

## 第五优先级：公开数据或代码

如果条件允许，BLE CS 呼吸数据和处理代码本身也能增加论文价值，特别是在该方向数据尚少时。

------

# 十一、按不同论文标准判断“是否充分”

由于你没有指定目标 venue，可以分三档看。

## 应用型、工程型或专题论文

目前贡献基本充分，前提是：

- 方法和数字统一；
- 删除矛盾内容；
- 完成最终收敛实验；
- 认真处理统计单位；
- 不过度声称 Phase 的普遍性结论。

------

## 一般综合型 sensing 论文

基本具备基础，但最好：

- 增加受试者；
- 强化 controlled vs human 对比；
- 完成统一实验；
- 清楚证明相对于迁移 baseline 的优势不是由预处理差异造成。

------

## 高要求系统/移动感知论文

目前可能偏临界，主要问题是：

- 只有 4 位受试者；
- 单个算法模块新颖性有限；
- Phase 机制尚未完全解耦；
- 最终主方法相对 Remote-only 的增量很小；
- 部分结论主要来自同一小规模数据集的多轮分析。

要向更高标准推进，最值得增加的不是新算法，而是：

1. 更大 cohort；
2. 跨日期/位置/硬件验证；
3. 受控工作点实验；
4. 更严格的 held-out evaluation。

------

# 十二、最终推荐的论文定位

我建议把文章定位成：

> **一篇 measurement-and-design paper，而不是单纯的 algorithm paper。**

它研究的不是：

> 怎样再设计一个更复杂的呼吸融合器？

而是：

> BLE CS 独有的双向、多 tone、多观测结构到底提供了什么有效分集？哪些信息稳定，哪些信息只在理想条件下可用？呼吸率与波形分别应该如何处理？

最终故事可以概括成：

> BreatheCS 系统研究了 BLE Channel Sounding 双向 PCT 测量在非接触呼吸感知中的融合规律。研究发现，72-tone frequency diversity 是最稳定、最主要的性能来源，而 endpoint amplitude 与 composite phase 之间的物理投影互补性并不会自动转化为实际 modal diversity gain。基于这一发现，BreatheCS 使用质量驱动的 tone aggregation，并为呼吸率估计和波形恢复分别设计谱域与相干波形分支。系统性实验进一步表明，composite phase 在受控周期运动中可用，但在真人自然呼吸中可靠性明显下降，无条件加入 Phase 对正确结果的破坏多于救援。因此，BLE CS 感知应根据统计可靠性选择观测，而不是默认融合全部物理变量。

------

## 最终判断

**文章的贡献已经足够形成一篇完整论文，但目前还不能依靠“新算法性能提升”单独站住。**

最稳健的叙事是：

1. **BLE CS 是一种不同于 WiFi CSI 的双向测量原语；**
2. **tone diversity 是主要、稳定的增益来源；**
3. **BPM 和 waveform 需要任务专用的融合域；**
4. **物理互补性不等于测量可靠性；**
5. **composite phase 是条件性观测，不应默认融合；**
6. **系统设计应追求可靠信息融合，而不是最大变量数量。**

其中最重要的一句是：

> **论文不需要证明 Phase 有用；论文需要证明 BLE CS 中什么信息真正可靠，以及为什么。**

只要全文围绕这一点组织，并主动限制结论范围，Phase 没有带来预期增益不仅不会破坏论文，反而可以成为文章最有辨识度的实验发现之一。
